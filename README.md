# intrinsic-neural-timescales-thesis
Intrinsic Neural Timescale Indices as Reliable Fingerprints of Brain Dynamics  This repository contains the code and thesis materials for my M.S. thesis in Biomedical Engineering at The City College of New York. 

## Project Overview
Intrinsic neural timescales describe how long neural signals retain information over time. In this thesis, I compared six autocorrelation-based INT indices across 400 cortical regions using resting-state fMRI data.

## INT Metrics
- AR(1)
- First zero lag
- Lag at 1/e
- Sum of positive autocorrelation
- Autocorrelation at half lag
- Exponential decay tau

## Main Analyses
- Test-retest reliability
- Subject discriminability
- Age-related trends
- Sex interactions
- Motion sensitivity
- Network-level comparisons

## Data
This project used the NKI-Rockland resting-state fMRI dataset. Raw data are not included in this repository.
